# LSR 大型 MCU 编辑性能测试库

文件：`LSR_Large_MCU_5120_Registers.db`

该文件是结构化生成的性能体验库，不对应某一款真实芯片，也不能用于芯片设计。规模取高端主流MCU/复杂双核MCU寄存器图的偏上限，用于稳定放大大库编辑性能差异：

- 160个外设Module；
- 每个Module包含32个32位Register，共5,120个Register；
- 每个Register包含8个4位BIT字段，共40,960个BIT；
- 每个BIT包含2个合法枚举值，共81,920个BIT取值；
- 四张业务表共128,160行，SQLite文件约6MB；
- Module地址按`0x1000`递增，Register地址按4字节递增，BIT覆盖`[31:0]`且互不重叠。

## 使用方法

1. 复制一份数据库后再测试，保留原始样本便于重复对比。
2. 使用LSR V1.15.1打开数据库。
3. 选择任意Module、Register、BIT或BIT取值，修改名称或描述并观察响应。
4. 使用`Ctrl+Z`和`Ctrl+Y`验证撤销、重做，再用`Ctrl+S`保存。

需求16优化普通编辑的撤销捕获和界面局部更新；需求17进一步把首次全库规则检查移到后台，并在`Ctrl+S`后只检查受影响Module。打开后界面可立即操作，状态栏显示后台检查状态。

## 本地基准

在项目固定Python 3.9.13环境中，优化前普通编辑约需4.70～5.36秒；优化后Module、Register、BIT和BIT取值编辑约需0.013～0.031秒。需求17优化后的全量规则检查约0.86～1.06秒，单个Module增量检查约0.024秒。具体数字会随电脑性能变化。
